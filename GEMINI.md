# Gemini Context: Personal Portfolio Website

## Project Overview

This is a personal portfolio website built with **Next.js 16**, **React 19**, and **Tailwind CSS 4**. The project features a distinct **Black & White aesthetic** where color is used selectively to guide user focus and interaction. The design emphasizes minimalism, using grainy video loops for backgrounds, bracketed UI elements (e.g., `[Button]`), and custom masonry layouts.

### Key Technologies
- **Framework:** Next.js 16 (App Router)
- **UI Library:** React 19
- **Styling:** Tailwind CSS 4
- **Language:** TypeScript
- **CMS:** Decap CMS (Local & Git-based) for Photography Portfolio
- **Animations:** CSS Keyframes & Tailwind Utilities (`animate-[...]`)

## Architecture & Structure

The project follows the standard Next.js App Router structure with feature-based organization and a strong emphasis on data-driven UI.

### Directory Map
- **`src/app/`**: Core application routes.
    - `page.tsx`: **Main Page**. Features a rotating playlist of grainy B&W videos, tagline, and central navigation.
    - `layout.tsx`: Global layout containing the `.grainy` overlay and font configurations.
    - `lens/`: **Photography Portfolio** (Powered by Decap CMS).
        - `page.tsx`: **Lens Landing Page**. Interactive carousel and category blocks with auto-generated covers.
        - `[category]/page.tsx`: **Dynamic Category Page**. Masonry gallery with location tags.
        - `location/[place]/page.tsx`: **Dynamic Location Page**. Masonry gallery filtered by location.
    - `build/`: **Projects Showcase**. 
        - Features a wide layout with alternating project cards.
        - Scroll-triggered activation: Projects colorize and gain opacity when they reach the viewport center.
    - `sound/`: **Music Portfolio**.
        - **Photo Wall:** 5-column bottom-aligned masonry wall with a fixed viewport height and top-clipping.
        - **Band Section:** Features an interactive logo with a soft radial mask (vignette) and band story.
        - **Covers & Rig:** Centralized list of covered songs and a centered three-column gear rig in the footer.
    - `about/`: CV and Resume. Standardized header with Resume download.
- **`src/components/`**: Reusable UI components.
    - `ui/BracketButton.tsx`: Core interactive button component `[ Text ]`.
    - `ui/Lightbox.tsx`: Core photo viewing modal with "click outside to close" behavior and dynamic metadata formatting.
    - `ProjectCard.tsx`: Blocky container design with scroll-triggered grayscale-to-color transitions.
    - `ProjectGallery.tsx`: **Project Detail Modal**. Split-screen carousel and description.
- **`src/data/`**: Static data files.
    - `projects.ts`: Central source for the Build section.
    - `music.ts`: Central Source for Music section.
- **`src/lib/`**: Utility and data fetching logic.
    - `photos.ts`: Logic to parse Decap CMS JSON files from `content/photos/`.
    - `photo-constants.ts`: Types and static category metadata for the Lens section.
- **`content/photos/`**: JSON files generated by Decap CMS containing photo metadata.
- **`public/`**: Static assets.
    - `admin/`: Decap CMS configuration (`config.yml`) and entry point (`index.html`).
    - `photos/uploads/`: CMS uploaded photos.
    - `musicPhotos/`, `projectPhotos/`, `videos/`: Static media.
- **`scripts/`**: 
    - `optimize.sh`: Native macOS script using `sips` to batch convert/resize raw photos (HEIC/PNG/JPG) to a web-optimized `readyToUpload` folder.

### Design System
- **Theme:** Predominantly Black & White (`#000000` / `#060606`).
- **Interaction:**
    - **Activation:** Elements transition from Grayscale/Dim -> Color/Bright based on **Scroll Position**, **Hover** (faster duration-300), or **Viewport Entry**.
    - **Alignment:** Consistent bottom-alignment for masonry walls to create a "grounded" aesthetic.
    - **Typography:** `SF Pro` (sans-serif) & `JetBrains Mono` (monospace).
- **Visuals:**
    - **Grain:** Global CSS utility `.grainy` for texture.
    - **Vignette:** Radial masks used to blend imagery into the black background.

## Building and Running

- **Development Server:** `npm run dev`
- **CMS Server (Local):** `npx decap-server` (Run concurrently with `npm run dev`, access via `http://localhost:3000/admin/index.html`)
- **Photo Optimization:** `npm run optimize <path-to-raw-photos>`
- **Build:** `npm run build`
- **Lint:** `npm run lint`

## Development Conventions

- **Styling:** Tailwind CSS 4 with custom utilities like `grainy` and `no-scrollbar`.
- **Data Management (Photography):** Do not manually edit code for photos. Use Decap CMS locally (`/admin/index.html`) to drag-and-drop optimize images. The CMS auto-generates JSON in `content/photos/` and saves assets to `public/photos/uploads/`.
- **Masonry Logic:** Use **Greedy Height Balancing** for fixed photo walls, and Tailwind's `columns-*` utilities for dynamic galleries.
- **Asset Handling:** Convert `.HEIC` files to `.jpg` using `sips` for web compatibility. ALWAYS run new photos through `npm run optimize` before uploading them to the CMS to prevent massive Git repo bloat.
